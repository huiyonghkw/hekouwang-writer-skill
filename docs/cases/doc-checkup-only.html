01 / 任务卡约束

领导说：先别改文件。

场景

已有方案稿，可能有错漏和数字对不上。

你说

先告诉我问题，不要直接改文件。

约束

检查档不授权重写或覆盖原文。

02 / 并排输入与输出

它交回的是问题表，不是改稿。

输入 你的要求
只检查错漏、歧义和数字关系。发现问题列出来，等我决定改不改。
输出格式 占位示例
位置问题建议
第 2 节「下月」缺明确日期保留待确认，问是否有批准日期
表 1合计与分项不一致复核来源，不能擅自挑一个数替换

表内条目为格式示意，不是某份真实方案的检查结果。

03 / 守住什么最多三条

发现问题，和决定怎么改，分开。

原句照抄

报告里的原句不改写，方便你回到原文。

建议只给方向

不直接生成替代段落冒充已解决。

工具分级

锯末词 / 句长是提醒；表格结构与算术可阻断。

04 / 检查结果本页状态

示意页：脚本未执行。

真实任务要对用户提供的原文件运行检查器，并如实报告实际输出。若随后授权修订，才进入修订模式并列出改动清单。
