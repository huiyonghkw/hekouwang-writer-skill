# 案例：家庭办事文档（王女士城乡居民养老保险提档补差，已脱敏）

> 本案例展示 hekouwang-writer-skill 的完整方法如何落在一篇真实的家庭办事文档上。
> 个人信息已脱敏（社保号中间位掩码）；事实内容保持原样，便于对照方法而非内容。

## 这篇文档的处方

| 决策点 | 选择 | 理由 |
|---|---|---|
| 原型 | 办事指南/家庭文档九段式 | 读者是家属，要办业务+存档 |
| 读者 | 完全不懂社保的家属 | 白话优先+术语表兜底 |
| 目的 | 12月去窗口前定档次、办业务 | 行动清单带时间和材料 |
| 风格档 | 正式事实 + 白话解释 | 政策口径不能口语化，解释必须口语化 |

## 成稿结构（实际目录）

```
摘要（先看这里）          ← 结论前置：谁/缴了多少/结局/三件事/怎么算
30秒导航                  ← 读者问题→章节路由表
本文怎么用                ← 写给谁/去哪办/边界/结论分两类
一、已确认的事实          ← 核心句 + 缴费表 + 核实出处
二、核算规则（三类业务）  ← 规则表 + 档次补贴表 + 养老金公式
三、她的账怎么补、补多少  ← 补差表（6档）+ 四方案对比 + 对账关系
四、时间线                ← 表 + "为什么2028年才领"块引用
五、行动清单              ← 复选框 + 当前进度 + 电话列表
六、政策依据与核实记录    ← 结论+出处+链接三列表
七、术语表（家属版）      ← 6个术语一句话
附：办理过程记录          ← 过程档案
```

## 方法落地示例（原文摘录）

### 1. 每节核心句（骨架层）

```markdown
## 一、已确认的事实

**核心句：她的缴费家底已全部核实。12年已缴，仅2025年断缴，个人缴费合计1,600元。**
```

### 2. 一句一事（文风层，拆句前后）

```markdown
改前：她2026年12月满60时只有14年；2027年保费不能提前缴（已确认），只能2027年当年缴，
      2027年底才满15年，待遇自次月起发。
改后：她2026年12月满60岁时只有14年。2027年保费不能提前缴（恩阳区城乡局已确认），
      只能2027年当年缴。到2027年底才满15年，待遇自次月起发。
```

### 3. 模态保留（不把"约"删成确定）

```markdown
| **月养老金（约）** | **661元** | **878元** | **921元** | **1,330元** |
```
表注同时写明：未计利息、未计基础养老金历年上调——推断的边界写清楚，不当成核定值。

### 4. 数字对账（质量层）

```markdown
**钱的对账关系**（以方案A为例）：12年补差46,400 + 2025补缴4,000 + 2026缴4,000
+ 2027缴4,000 = **58,400元** = 表里"需自筹"，两边对得上。
```
两个独立算出的数字互相咬合，是文档可信度的锚点。

### 5. 枚举改列表（文风层）

```markdown
改前：电话：恩阳区城乡局 0827-3369682；恩阳区居保局 0827-3369685；……
改后：**电话**：
      - 恩阳区城乡局 0827-3369682（首选）
      - 恩阳区居保局 0827-3369685
      - ……
```

### 6. 结论+出处+链接一表（证据层）

| 文件/答复 | 关键内容 | 链接 |
|---|---|---|
| 恩阳区城乡局电话答复（2026-10-14） | 2013-2018每年100元、系统可查；…… | 电话，无链接 |
| 国发〔2014〕8号 | 年满60周岁+累计缴费满15年方可领取 | [原文](https://www.gov.cn/…) |

没有链接的来源如实写"电话，无链接"，不假装有出处。

## 这篇文档踩过并记入台账的坑

- 把税务 APP 记录（2019年起）当成全部缴费记录 → 漏了6年。教训：**单一渠道记录不等于全量，交叉核实**（LRN-20261014-001）。
- 表格列加了列忘改标题（"两个方案"挂着4列）→ 机械检查：标题数量词与列数对不上。教训：**成文后跑 doc_lint，标题与内容必须一致**。
- 补差总额算错一次（39,750 vs 正确的50,050）→ 教训：**合计数字必须独立复算，表间对账**。这条直接催生了 check_fidelity.py——后来"回本年龄算错一年"也是靠逐格重算才发现，现在这类错误机器能查。
- 办事顺序被新电话答复推翻（"现在补缴2025"→"2027年1月一次办齐"）→ 教训：**办事文档必须留"答复日期"，新答复替换旧答复时要标注旧条目作废，不能留两套矛盾方案**。
